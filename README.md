# memory game

A simple, responsive memory matching game built with React, TypeScript, and Vite.


## Live Link

https://kg-memory-card.netlify.app/

## Features

- Timer on game start/finish
- Best Score
- Difficulty: Easy, Medium, Hard
- Frontend testing(unit), ready for e2e
- Git Workflow

## Tech Stack

**Frontend:** Vite, React, React Router, SCSS

**Linters:** ESLint, StyleLint

**Tests:** React Testing Library, Vitest

**Server:** Netlify

## Run Locally

Clone the project

```bash
git clone https://github.com/kgallarin/memory-game.git
```

```bash
$ npm install
```

```bash
$ npm run dev
```

## Running Tests

To run frontend unit tests, run the following command

```bash
$ npm run test:unit
```
